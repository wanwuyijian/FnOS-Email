# fnOS 邮件定时助手 (fn-mail-assistant)

为飞牛 **fnOS（ARM）** 打造的本地邮件应用，以 **FPK** 形式安装。基于 Python 3 标准库实现，**无任何第三方依赖**，适配 ARM 设备与低配硬件。

- 邮件收发：支持 **SMTP / IMAP / POP3**，内置 163、阿里云邮箱预设
- 定时任务：把本地文件/文件夹按计划自动发送到指定收件人
- 稳定优先：守护自动重启、崩溃日志、段错误捕获、一键导出诊断包
- 升级无损：升级/重装时账号、任务、发送历史完整保留

---

## 功能特性

### 邮件收发
- 发送：SMTP（SSL），支持多收件人、抄送、正文、多附件
- 收取：IMAP（推荐）与 POP3 双协议，可浏览邮件列表与正文
- 内置预设（自动填好服务器/端口）：

  | 预设 | SMTP | POP3 | IMAP |
  | --- | --- | --- | --- |
  | 网易 163 | smtp.163.com:465 | pop.163.com:995 | imap.163.com:993 |
  | 阿里云邮箱(个人) | smtp.aliyun.com:465 | pop.aliyun.com:995 | imap.aliyun.com:993 |
  | 阿里云邮箱(企业版) | smtp.qiye.aliyun.com:465 | pop.qiye.aliyun.com:995 | imap.qiye.aliyun.com:993 |
  | 自定义 | 手动填写 | 手动填写 | 手动填写 |

- 163 邮箱适配：登录前自动发送 ID 命令伪装官方客户端，规避 `Unsafe Login`。

### 定时任务
- 触发方式：`一次性 / 每天 / 每周 / 每月 / 每 N 分钟`
- 附件来源：单个文件、**文件夹（递归）**、通配符（如 `/vol1/backup/**`）
- **文件类型过滤**：只发送文件夹内指定类型的文件（如 `.pdf, .xlsx, .jpg`）
  - 仅对「文件夹 / 通配符」展开出的文件生效；你手动单独添加的具体文件不受过滤
- 可选将多个附件打包为一个 zip
- 正文支持占位符：`{date}` `{time}` `{datetime}` `{files}` `{count}`
- 断线补发（catch-up）：设备离线错过的任务在恢复后补发
- 失败自动重试，每封发送结果记录到历史

### 安全与稳定性
- 管理密码：PBKDF2-HMAC-SHA256（10 万次迭代）存储，Bearer Token 会话（7 天）
- **修改管理密码**：系统页可修改，修改后其它设备登录被强制退出
- bash 守护进程：Python 崩溃后自动重启（退避 3s → 60s）
- 脚本异常 / 段错误写入 `crash/` 目录，日志按 1MB × 5 轮转
- 一键导出**诊断包**（日志 + 崩溃记录 + 环境信息），方便发给 AI 排查

## 安装

1. 从本仓库 [Releases](../../releases) 下载对应版本的 `fn-mail-assistant-<版本>_arm.fpk`。
2. 打开 fnOS **应用中心 → 手动安装**，选择该 `.fpk` 文件。
3. 安装时**选择你希望安装到的存储空间**（应用不会强制装到系统分区）。
4. 安装完成后，桌面会出现「邮件定时助手」图标。

> **升级**：同样从 Releases 下载新版 `.fpk`，在应用中心选择「升级」。账号、任务、历史数据会自动保留。

---

## 快速开始

1. **设置管理密码**：首次打开应用网页，按提示设置管理密码（≥6 位）。
2. **添加邮箱账号**：进入「邮箱账号」页，选择预设（如"网易163邮箱"），填入邮箱地址与**授权码**（不是登录密码），点击「测试」确认收发正常后保存。
3. **发送邮件**：进入「写邮件」页，选发件账号、填收件人、主题、正文与附件，点击「立即发送」。
4. **配置定时任务**：进入「定时任务」页 → 新建任务 → 选择账号、收件人、附件路径与触发规则，保存后即按计划自动发送。

### 关于邮箱授权码
网易 163、阿里云邮箱需先在网页版邮箱中**开启 SMTP/IMAP/POP3 服务**，并生成**授权码**，在本应用中使用该授权码而非登录密码：

- 163：设置 → POP3/SMTP/IMAP → 开启并生成授权码
- 阿里云：设置 → 账户 → POP3/IMAP/SMTP 服务 → 开启

## 定时任务字段说明

| 字段 | 说明 |
| --- | --- |
| 名称 | 任务名，用于列表与历史记录展示 |
| 发件账号 | 选择已配置的邮箱账号 |
| 收件人 / 抄送 | 多个用逗号或分号分隔 |
| 主题 / 正文 | 正文支持 `{date}` 等占位符 |
| 附件 | 文件、文件夹（递归）、通配符，每行一个 |
| **文件类型过滤** | 只发送文件夹/通配符内的指定类型，如 `.pdf, .xlsx, .jpg`；留空=全部 |
| 打包为 zip | 勾选后把所有附件合并成一个 zip 发送 |
| 触发方式 | 一次性 / 每天 / 每周 / 每月 / 每 N 分钟 |
| 断线补发 | 设备离线错过时是否补发 |

## 目录结构

```
.
├── app/                  # 应用源码（运行时被打包进 app.tgz）
│   ├── server.py         # HTTP API + 静态页服务
│   ├── mailer.py         # SMTP / IMAP / POP3 收发
│   ├── scheduler.py      # 定时任务引擎
│   ├── storage.py        # JSON 原子存储（含 schema 迁移）
│   ├── applog.py         # 轮转日志 + 崩溃捕获
│   ├── bin/launcher.sh   # bash 守护启动脚本
│   ├── web/              # 前端（原生 HTML/CSS/JS 单页应用）
│   └── ui/               # fnOS 桌面入口配置与图标
├── fpk/                  # fnOS 包定义
│   ├── manifest          # 包元信息（版本、端口、入口等）
│   ├── config/           # 权限与资源声明
│   ├── cmd/              # 生命周期脚本（安装/卸载/升级/启停）
│   ├── wizard/install    # 安装向导说明
│   └── ICON*.PNG         # 应用图标
├── build/
│   └── build_fpk.py      # 打包脚本（Windows 可用）
└── dist/                 # 打包产物（.fpk 安装包）
```

## 本地开发与打包

**本地调试运行**：

```bash
python app/server.py
# 浏览器访问 http://127.0.0.1:8322
# 数据写入 app/devvar/（本地调试目录，不参与打包）
```

**重新打包 FPK**：

```bash
python build/build_fpk.py
# 产物输出到 dist/fn-mail-assistant-<版本>_arm.fpk
```

打包脚本会自动校验 `manifest`、JSON 配置、生命周期脚本、图标与桌面入口格式，并确保包内脚本具备可执行位、以 LF 换行（Windows 下打包必需）。

**发版流程**：修改 `fpk/manifest` 中的 `version` 与 `changelog` → 运行打包脚本 → 将新的 `.fpk` 发布到 GitHub Releases。

## 常见问题

**Q：安装后桌面没有图标？**
下拉刷新桌面，或注销后重新登录即可。若仍无图标，请确认应用已成功启动（见下一条）。

**Q：应用打不开 / 页面空白？**
1. 确认设备架构为 ARM；2. 检查端口 `8322` 是否被占用；3. 到应用数据目录查看日志，或在应用内「系统」页下载诊断包。

**Q：能装到存储空间而不是系统分区吗？**
可以。安装时选择存储空间即可，本应用未强制系统分区安装。

**Q：升级会不会丢数据？**
不会。账号、任务、发送历史保存在应用数据目录中，升级/重装时自动保留。

**Q：发送失败怎么排查？**
在「系统」页点击「下载诊断包」，把 zip 发给 AI 即可定位。常见原因是授权码错误、未开启 SMTP/IMAP 服务，或网络受限。

**Q：邮件正文乱码？**
本应用收发均按 UTF-8 / 常见字符集解码，若仍乱码请在诊断包中附上原始邮件。
